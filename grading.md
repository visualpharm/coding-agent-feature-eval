## sonnet-medium
- Bug: report summary labels the ARS `plan.total` as USD ("USD 4.895.000"); the one number the visitor reads is wrong.
- Bug: a bill answer never reaches sizing (`monthlyKwh:null` + `monthlyBillArs`); the wizard route derives kWh from the bill, the chat does not, so bill users get the 14-panel sample.
- Spec miss: prompt still names [installer] twice and still allows 1–3 sentences/60 words; REMINDER untouched.
- Lane: extracted `reportAnalysis` into `lib/quote-report-analysis.js`. The lib home is the better architecture (CLAUDE.md: server.js is wiring) and it avoids the require cycle the others dodge with lazy requires, but it was unnecessary for reuse (already exported), touched 96 lines of a file outside the lane while siblings were live, and belongs in its own commit/PR. Verdict: low-risk scope creep.
- Strength: the only test suite that stubs both Places and OpenRouter through one `fetchImpl` and drives the real lead+analysis libs; `preview:true` keeps `chatSuggest` from creating leads. After `done`, a new price question restarts the flow from scratch (second lead).

## opus-low
- Strengths: `estimate-deps.js` is a faithful copy of the `/api/quote/analysis` intake (bill→kWh, country, consent); link built through the repo's `absoluteQuoteUrl`; interim "armando tu informe" message; live run found and fixed two real bugs ("la 1" pick, duplicated pending question).
- Cleanest separation: pure state machine (`estimate.js`) vs wiring (`estimate-deps.js`), narrow test seam.
- Defects: no interruption handling at the address step; after `done` a new price question re-enters a fresh flow and creates another lead; escalated-thread note still names [installer]; `parseContact` accepts any 8–15 digit string without `lib/whatsapp`.
- Gate/lane: `.gitignore` edit and server exports are outside lane but trivial; trailer deviates from the prescribed one (signed as Opus).
- Without `estimateDeps` (sweep, `chatSuggest`) the estimator is silently bypassed, so a mid-flow thread answered by the sweep gets the old LLM behaviour.

## fable-low
- Strengths: broadest deterministic coverage — inline address in the opener, exclusions ("ya tengo la cotización", "cuánto cuesta la visita"), out-of-service candidates, hard-guardrail-inside-flow test, failure path linking to `/quote/start`, `reportReady` prompt variant, `dryRun` for panel previews, no flow re-entry after a report.
- Interruption handled at every step, also under LLM fallback/402 (shown in the e2e transcript).
- Defects: `toLocaleString('en-US')` in Spanish copy ("USD 6,311", "4,069 kWh"); synthetic `req` drops geo-IP bias for the geocoder; link uses the raw host header (Opus's `absoluteQuoteUrl` is the same code, but centralised).
- Reordered the guardrail gate (`hardWins` excludes softOnce) — behaviour-preserving per tests, but a subtle change to shared responder logic.
- Extra scope: mails the PDF on completion (matches the wizard route, needed a server export).

## Ranking
Fable-low first by a hair over Opus-low, Sonnet-medium a clear third. Fable and Opus both ship a working, spec-shaped flow with a real e2e transcript ending in a `/quote/results/` link; the difference is in edges. Fable covers more of the conversational reality (inline address, questions at any step, no second lead after the report, exclusions for non-estimate price questions) and left the prompt cleanest, but prints en-US number formatting inside voseo Spanish and loses the geo-IP bias. Opus is the more disciplined engineer (route-faithful deps module, single URL helper, interim message, live bug-fixes) but skips interruption detection at the address step, re-enters the flow after `done`, and signed commits with the wrong trailer. Sonnet is disqualified from the top by two shipping bugs the others do not have — the ARS total labelled USD and bill answers silently sized as the sample home — plus an unfinished prompt cleanup ([installer] still named, 1–3 sentences) and an out-of-lane 96-line refactor that reuse did not require; its unit-test design (single `fetchImpl`, real libs) was the best of the three but its assertions were too loose to catch its own bugs.
